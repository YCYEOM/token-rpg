캐릭터가 됩니다

Claude Code·Codex·Gemini CLI 에 쓴 토큰으로 자라는 턴제 RPG입니다. 출력 토큰은 공격력, 캐시는 방어력, thinking 은 치명타가 됩니다. 코딩한 만큼 강해집니다.

macOS 다운로드 윈도우 · 리눅스
무료 · 오픈소스(MIT) · 의존성 없음

쓴 토큰이 그대로 스탯입니다

로컬 사용 기록의 토큰 수만 읽습니다. 쓰는 방식이 곧 빌드입니다.

입력 + 출력
EXP

ATK · HP

thinking 토큰

API 호출 수
SPD

놀 거리

버그 벌레부터 루트 권한의 군주까지, 개발자의 적 75종이 던전 보스입니다.

턴제 자동 전투

스테이지를 고르면 자동으로 싸웁니다. 속도가 빠르면 먼저 치고, 치명타는 thinking 토큰에서 나옵니다.

스탯 배분

레벨마다 받은 포인트를 공격·체력·방어·치명타·속도에 나눕니다. 화력 몰빵도, 버티는 빌드도 됩니다.

환생과 영구 특성

벽에 막히면 환생합니다. 모은 혼으로 영구 특성을 사서 다음 판에 더 깊이 내려갑니다.

유물

보스가 가끔 유물을 떨어뜨립니다. 일반부터 신화까지 다섯 등급이고, 깊은 층에서 나올수록 셉니다.

자동 반복

알아서 오르고, 막히면 그 자리에서 유물을 캡니다. 아직 못 모은 곳은 칸에 ◆·★ 로 표시됩니다.

미션 · 주간 레이드 · 원정

미션과 레이드는 실제로 쓴 토큰으로 찹니다. 저장을 고쳐도 진행도는 바뀌지 않습니다.

다운로드

Python 3.9 이상만 있으면 됩니다. 표준 라이브러리만 씁니다.

🍎 macOS

메뉴 막대에 상주합니다. 아이콘 옆에 레벨과 진행률이 뜨고, 누르면 팝오버에서 바로 플레이합니다.
DMG 받기
DMG 안의 Token RPG.app 을 응용 프로그램 폴더로 옮깁니다. 서명하지 않은 빌드라 처음 한 번은 앱을 우클릭 → 열기 로 엽니다.

🪟 윈도우

알림 영역(트레이)에 상주합니다. 아이콘을 누르면 게임 창이 열립니다.
pipx install token-rpg
token-rpg-tray --startup on
두 번째 줄은 로그인할 때 자동으로 켜 둡니다.

🐧 리눅스 · 터미널

브라우저에서 엽니다. macOS·윈도우에서도 같은 명령으로 됩니다.
pipx install token-rpg
token-rpg open
uv tool install token-rpg·pip install token-rpg 도 됩니다.

지원하는 AI 툴

Claude CodeCodex CLIGemini CLI
  • 여러 툴의 사용량을 한 캐릭터로 합칩니다.
  • 여러 PC 의 기록도 스냅샷 폴더를 동기화해 합칠 수 있습니다.
  • 웹 채팅(ChatGPT·Gemini 웹)과 IDE 확장은 로컬 기록이 없어 잡히지 않습니다.

개인정보

  • 사용 기록의 토큰 수(usage)만 읽습니다. 대화 내용은 쓰지 않습니다.
  • 읽기 전용입니다. 원본 로그를 고치지 않습니다.
  • 아무것도 밖으로 보내지 않습니다. 게임 데이터는 내 PC 에만 저장합니다.

자주 묻는 것

돈이 드나요?

무료입니다. MIT 라이선스 오픈소스이고, 게임 안에 결제가 없습니다.

토큰을 더 쓰게 만드는 게임인가요?

아닙니다. 평소대로 코딩한 기록을 읽을 뿐입니다. 환생 기운에 상한이 있어서 토큰을 몰아 써도 빨라지는 데 한계가 있습니다.

업데이트는 어떻게 하나요?

게임 화면의 업데이트 버튼을 누르면 됩니다. 메뉴 막대 앱은 새 DMG 를 받아 앱을 직접 갈아끼웁니다. 터미널에서는 token-rpg update 입니다.

예전 기록부터 세나요?

기본은 설치한 시점부터 셉니다. token-rpg since 로 언제부터 셀지 바꿀 수 있습니다.
